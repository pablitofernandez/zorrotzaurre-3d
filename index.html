Controles

  • WASD / flechas: moverse y girar
  • Q E: girar · R F: mirar arriba / abajo
  • Ratón: mirar (arrastra, o clic para capturar y Esc para soltar)
  • Shift: andar más rápido
  • Minimapa o lista: saltar a una estancia
  • 1 2 3: edificio / planta / recorrer · H: esta ayuda
  • RePág AvPág: subir / bajar de planta
  • - +: campo de visión (dentro de la vivienda)
  • V: describir lo que tienes delante (lector de pantalla)
  • Mitad izquierda: arrastra para caminar
  • Mitad derecha: arrastra para mirar
  • 📱: mirar moviendo el móvil
  • Minimapa o botones: saltar a una estancia
  • 🏢: elegir la planta · 👁️: campo de visión
  • Fuera: un dedo gira, dos dedos acercan o desplazan
